# 小型世界モデルの空間記憶を検証する研究キット

これは、約27.7万パラメータの小さな再帰型世界モデルを使い、**「過去を利用できること」と「経路が変わっても場所を理解できること」を区別して調べる**ためのキットです。

[GitHubのコードとキット](https://github.com/qwel64/spatial-memory-kit) · [Hugging Faceのモデルとキット](https://huggingface.co/nao1357/spatial-memory-kit-v0.1) · [実測軌跡の再生ページ](https://huggingface.co/spaces/nao1357/spatial-memory-kit)

モデルは言葉で答えるLLMではありません。16×16の白黒画像、接触・移動・energyの5値、直前の行動から、内部の128個の値を更新します。その状態から、指定された行動を取った1歩先・5歩先の感覚を予測します。位置座標、地図、経路IDを脳本体への入力・教師には使っていません。座標はシミュレータと評価・表示側にあります。

## 何が分かり、何がまだできなかったか

元の研究では、感覚予測の改善と、限られた場面で履歴を使うことを確認しました。一方、経路・向き・距離を変えても使える空間理解を、同じモデルで安定して示すところまでは到達していません。最新モデルの自由探索や長期生存も未測定です。

AIエージェントを使って実装・解析・監査・文書化した探索的な個人研究です。エージェントによる確認は、外部査読や別の研究室による独立再現とは区別しています。

たとえば説明用の `coupled_b7_s33101` は、元のA1課題では1歩先・5歩先の画像候補をともに100%識別できました。同じ重みで経路を組み替えたA2では42.1875%・37.5%に下がりました。直近8観測より前の状態を消すとA2は25%・25%だったので、一部の履歴はまだ利用しています。しかし、これは経路を越えて場所を安定して理解できた、という結果ではありません。

ここでの百分率は元の複数試行の評価値です。このキットの24軌跡は、モデルと経路ごとに事前選択した1試行の記録です。軌跡を再生するだけで元の集計値全体を再計算できる、とはしていません。

## 中身

- 4条件×3組の学習済みモデル12個と、それぞれに対応する未学習モデル12個。
- 全24個をFP32のsafetensors形式で収録。各モデルのパラメータ数は276,501。
- 学習済み12個×2経路、計24軌跡の実測記録。各軌跡は観測時刻0〜48の49時点。
- 入力画像、未来の正解画像、予測画像、128次元の状態、行動から作った予測状態。
- 保存ファイル検証、同じ入力での再推論、小さな学習実行の確認用コマンド。

4条件は、観測更新と行動遷移を分ける `separate`、行動遷移を観測更新にも使う `coupled` と、遷移GRUの初期bias 2 / 7 の組み合わせです。seedは33101・33113・33127です。同じ組の中で条件を対応させています。12個を12回の完全に独立した反復とは数えません。元の学習は各モデル1,125 epoch・18,000 updateでした。

## 動かし方

Python 3.12と、その環境に適したPyTorchを使い、ダウンロードしたキットのルートで実行します。CPUで確認できます。

```bash
python -m pip install -r requirements-tested.txt
python -m pip install --no-deps -e .
python -m spatial_memory_kit verify --root .
python -m spatial_memory_kit replay --root . --model coupled_b7_s33101 --route a_one --state trained
python -m spatial_memory_kit replay --root . --model coupled_b7_s33101 --route a_two --state trained
python -m spatial_memory_kit replay --root . --model coupled_b7_s33101 --route a_two --state initial
python -m spatial_memory_kit replay --root . --model coupled_b7_s33101 --route a_two --state trained --history reset8
python -m spatial_memory_kit replay --root . --model coupled_b7_s33101 --route a_two --state trained --history reset-now
python -m spatial_memory_kit smoke-train --root . --output smoke-run
```

`verify` は配布物の整合性確認です。`replay` は保存済みの観測列を使ってモデルの計算を実行します。`--state initial` は対応する未学習モデルとの比較です。`smoke-train` は小さな学習処理が動くかの確認であり、元の全学習の再実行でも、新しい空間記憶の成功判定でもありません。

`--history full / reset8 / reset-now` で、全履歴・直近8観測まで・現在の観測だけを比べられます。[比較スクリプト](examples/compare_memory_controls.py) と [144条件の保存結果](examples/memory_control_results.json) は、12モデル×2経路×学習済み/未学習×3履歴条件を収録します。各条件は選んだ1エピソードで、49時点を49個の独立標本とは数えません。

公開準備で全24学習済み軌跡をCPUで再計算した最大絶対誤差は約5.69×10⁻⁶、許容値は10⁻⁵でした。重みの形式変換は全テンソルで完全一致です。40更新の小さな学習実行は検証lossを約0.157437から0.076054へ下げましたが、画像誤差は1歩先・5歩先とも現在画像コピー対照を上回っていません。これを空間記憶の成功とは扱いません。

## 状態の動画・ヒートマップの読み方

時刻tの `h` は、そこまでに見たものを取り込んだ状態です。`prior` は直前の行動を使って作る観測前の予測です。`z1` と `z5` は、未来の観測を見ず、指定した行動だけを使って進めた1歩先・5歩先の状態です。

`coupled` の最初の時刻では、直前の行動が存在しないことをゼロベクトルで表します。この時点のpriorは計算されても観測更新に採用されません。`separate` は観測更新用のprior自体を計算しません。表示はこの違いを明記します。

128個の値を8×16に並べても、それは物理的な神経配線図でも、そのまま読み取れる地図でもありません。どの値がどの場所を因果的に担うのかまで同定したものではなく、異なるモデルの同じ番号に同じ意味があるとも仮定しません。静的な説明図の矢印は実装上のデータの流れを示します。

## 公開版の範囲と注意点

このv0.1は最終v33のモデル比較と、実測軌跡の再生・再推論に範囲を絞っています。元研究の歴代39候補すべて、全学習データ、すべての課題や評価コード、約90分の音声動画は含めていません。外部の研究室で独立再現されたもの、査読を通過したもの、汎用的に自律行動する人工生物としての公開ではありません。

未学習モデルでも履歴の情報が残ることがあります。だから「状態を消すと悪化した」だけで、予測学習がその能力を作ったとは断定できません。また、ある経路で学習した線形の読み出しが別経路で失敗しても、「内部に位置情報が一切ない」とは言えません。読み方が移らないことと、情報が存在しないことを区別します。

説明に使う1個のモデルは事前に選んだ具体例です。全体で最も優れたモデルという意味ではありません。条件間の差はseedによって向きが変わるため、1個だけから構造の優劣を決めないでください。

詳しい仕様と限界は [methods](docs/methods.md) と [results](docs/results.md) にあります。自作部分は [MIT License](LICENSE) で公開しています。利用するライブラリにはそれぞれのライセンスが適用されます。
